# Jarvis — Seu Sistema de Chief of Staff Pessoal

Este é um kit inicial para rodar com **Claude Code**.

## Como começar (passos rápidos)

1. Instale o Claude Code (precisa de conta Anthropic Pro/Max ou superior).
2. Abra esta pasta `jarvis/` no Claude Code.
3. Preencha os arquivos em `system/` (principalmente `context.md`).
4. Diga ao Claude:
   > "Leia o CLAUDE.md e todos os arquivos de system/. A partir de agora você é o Jarvis. Confirme que entendeu e me ajude a preencher o que está faltando."

## Comandos naturais que já funcionam

- "Organize minha cabeça" / "Bagunça mental"

- "Revisão do dia"
- "Revisão semanal"
- "Otimize meu fluxo"
- "O que está me travando?"
- "Atualize o sistema com o que conversamos"
