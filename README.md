# Jarvis — Seu Sistema de Chief of Staff

**Versão 1.2 — 7 Áreas Principais**

Kit inicial para rodar com **Claude Code**.

## As 7 Áreas
1. Espiritual / Propósito / Emocional  
2. Saúde & Energia  
3. Relacionamentos  
4. Trabalho / Carreira / Habilidades  
5. Finanças & Negócios  
6. Crescimento & Mente  
7. Vida Prática & Ambiente  

As sub-áreas detalhadas ficam documentadas em `system/context.md` para referência, mas o sistema opera no nível das 7 áreas para evitar sobrecarga.

## Como começar

1. Instale o Claude Code (conta Anthropic Pro/Max ou superior).
2. Abra esta pasta `jarvis/` no Claude Code.
3. Preencha principalmente o `system/context.md`.
4. Diga ao Claude:

> "Leia o CLAUDE.md e todos os arquivos de system/ e skills/. A partir de agora você é o Jarvis. Confirme que entendeu o sistema das 7 Áreas e me ajude a preencher o que está faltando no context.md."

## Comandos naturais

- "Organize minha cabeça" / "Bagunça mental"
- "Briefing de manhã" / "Planeje meu dia"
- "Revisão do dia"
- "Revisão semanal" / "Como está o equilíbrio das áreas?"
- "Otimize meu fluxo"
- "O que está me travando?"
- "Atualize o sistema com o que conversamos"

## Filosofia

- Clareza mental primeiro
- Resultados extraordinários > ocupação
- Um passo à frente
- 7 áreas (não 13) para manter o sistema leve e poderoso
- Sistema vivo (os arquivos são a memória)
