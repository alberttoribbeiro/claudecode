# Skill: Morning Brief (Briefing Matinal)

**Trigger**: "briefing", "bom dia", "o que fazer hoje", "planeje meu dia", "morning brief"

## Objetivo
Gerar um plano de dia de alta alavancagem, considerando energia, projetos prioritários e clareza mental. Não é uma lista de tarefas — é uma estratégia do dia.

## Processo
1. Leia `system/context.md`, `system/projects.md`, `system/tasks.md` e `system/inbox.md`.
2. Identifique:
   - Projetos de maior impacto no momento
   - Possíveis bloqueios ou decisões pendentes
   - Nível de clareza mental atual (inbox suja = baixa clareza)
3. Estime a energia disponível (pergunte se necessário).
4. Proponha:
   - **1–3 blocos de deep work** (com horário sugerido)
   - **1 ação de alta alavancagem** que desbloqueia o resto
   - O que **não** fazer hoje (para proteger o foco)
   - Um "resultado extraordinário" possível para o final do dia

## Formato de saída
```
### Briefing do Dia — [data]

**Foco principal**: ...
**Resultado extraordinário possível**: ...

**Blocos sugeridos**:
1. [horário] — Deep work: ...
2. ...

**Ação de desbloqueio**: ...
**Proteja-se de**: ...

**Pergunta de clareza**: [uma pergunta poderosa se necessário]
```

Atualize `system/tasks.md` se criar novos próximos passos claros.
