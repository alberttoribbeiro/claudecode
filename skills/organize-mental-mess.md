# Skill: Organizar Bagunça Mental

**Trigger**: "organize minha cabeça", "bagunça mental", "despejar", "processar inbox", "estou sobrecarregado", "clareza"

## Objetivo
Transformar caos mental em clareza e próximos passos concretos. Esta é a skill mais importante do sistema.

## Processo
1. Peça (ou use o que já está em `system/inbox.md`) o despejo completo.
2. Classifique cada item em:
   - **Projeto** (precisa de múltiplos passos) → `system/projects.md`
   - **Próximo passo concreto** → `system/tasks.md`
   - **Decisão pendente** → destacar e ajudar a decidir
   - **Preocupação / emoção** → nomear e sugerir o que fazer com ela
   - **Ideia / insight** → capturar e arquivar ou conectar a projeto
   - **Lixo / não importante** → descartar conscientemente
3. Identifique o que está realmente te travando (geralmente 1–3 itens).
4. Proponha a ordem de processamento (o que resolve primeiro gera mais alívio e momentum).
5. Atualize os arquivos de sistema.

## Formato de saída
```
### Clareza Restaurada

**O que estava pesando**:
- ...

**Transformado em**:
- Projetos atualizados: ...
- Próximos passos claros: ...
- Decisões necessárias: ...

**O que pode ser ignorado por agora**: ...

**Próxima ação de maior alívio**: ...
```

Seja empático mas firme. Clareza é libertadora.
