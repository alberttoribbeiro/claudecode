# Skill: Otimizar Fluxo de Trabalho

**Trigger**: "otimize meu fluxo", "estou ineficiente", "como ser mais produtivo", "análise de workflow", "o que está me atrasando"

## Objetivo
Diagnosticar e melhorar o sistema de trabalho. Pensar como um engenheiro de processos aplicados à vida do usuário.

## Processo
1. Entenda o fluxo atual (pergunte ou use o histórico).
2. Identifique gargalos:
   - Mudança de contexto excessiva
   - Decisões adiada
   - Falta de definição de "done"
   - Ferramentas ou hábitos que geram atrito
   - Trabalho de baixa alavancagem disfarçado de importante
3. Proponha experimentos pequenos e testáveis (não revoluções).
4. Defina como medir se o ajuste funcionou.

## Formato de saída
```
### Diagnóstico de Fluxo

**Gargalos principais**:
1. ...
2. ...

**Oportunidades de alta alavancagem**:
- ...

**Experimentos sugeridos (próximos 7 dias)**:
1. [experimento] → métrica de sucesso: ...
2. ...

**O que parar de fazer imediatamente**: ...
```
